Русский

Кто пользуется. Tank Audit Publisher — личная автоматизация автора канала «Танковый аудит». Доступ к своим аккаунтам Google/YouTube и TikTok предоставляет только сам владелец канала. Посторонние пользователи не регистрируются и не авторизуются.

Какие данные. OAuth-токены доступа к аккаунту владельца (YouTube: загрузка и управление своими видео; TikTok: публикация своих видео) и метаданные собственных роликов (файл видео, обложка, название, описание, теги, плейлист, время публикации). Персональные данные зрителей, комментарии и данные других пользователей не собираются.

Как используются. Только для загрузки и настройки собственных роликов владельца на его канале. Данные не продаются, не передаются третьим лицам и не используются для рекламы.

Где хранятся. На собственном сервере владельца (n8n), в зашифрованном хранилище учётных данных. Файлы роликов удаляются после публикации.

Использование данных Google. Использование и передача информации, полученной через API Google, соответствуют Google API Services User Data Policy, включая требования ограниченного использования (Limited Use). Сервис использует YouTube API Services и подчиняется Условиям использования YouTube и Политике конфиденциальности Google.

Удаление данных. Владелец может в любой момент удалить свои данные: отозвать доступ (см. ниже) — токены удаляются с сервера автоматически; метаданные и файлы роликов удаляются после публикации и не хранятся дольше 30 дней.

Отзыв доступа. Доступ можно отозвать в любой момент: настройки безопасности Google (раздел «Сторонние приложения») и в настройках приложений TikTok. После отзыва токены перестают действовать и удаляются с сервера.

English

Who uses it. Tank Audit Publisher is a private automation of the author of the “Tank Audit” channel. Only the channel owner grants access to his own Google/YouTube and TikTok accounts. No other users sign up or log in.

Data. OAuth access tokens for the owner’s accounts (YouTube: uploading and managing own videos; TikTok: posting own videos) and metadata of the owner’s own videos (video file, thumbnail, title, description, tags, playlist, publish time). No viewer data, comments or other users’ data are collected.

Use. Solely to upload and configure the owner’s own videos on his channel. Data is never sold, shared with third parties or used for advertising.

Storage. On the owner’s own server (n8n), in an encrypted credential store. Video files are deleted after publishing.

Google user data. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This service uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Data deletion. The owner can delete his data at any time by revoking access (see below) — tokens are then removed from the server automatically; video files and metadata are deleted after publishing and kept no longer than 30 days.

Revoking access. Access can be revoked at any time at Google account permissions and in TikTok app settings; tokens then stop working and are deleted from the server.

Contact. GitHub Issues.
